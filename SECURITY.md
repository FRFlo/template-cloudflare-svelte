# Signaler une vulnérabilité

Ne publiez pas de vulnérabilité, d’identifiant, de secret ni de donnée
personnelle dans une issue publique.

Si les signalements privés de vulnérabilités GitHub sont activés pour ce dépôt,
utilisez cette fonctionnalité pour contacter les mainteneurs. Sinon, contactez
les mainteneurs par un canal privé avant toute divulgation publique.

Dans votre signalement, indiquez les étapes de reproduction, l’impact observé,
les versions concernées et, si possible, une proposition de correction. Ne
joignez jamais de secrets réels ou de données d’utilisateurs.
